# Prompts

The prompts that produced this project, in order. In VSCode with the Claude Code extension,
open this folder and reference them (e.g. `@prompts/01_original_task.md`) to continue or
regenerate any part. The LLM runtime prompts (anti-hallucination system prompt, clarify prompt)
live in `rag_engine.py` (`SYSTEM_PROMPT`, `CLARIFY_PROMPT`).
